# 🧩 Tic-Tac-Toe
 
Aplicación de escritorio en Python que implementa el clásico juego del gato (Tic-Tac-Toe) para dos jugadores

## Características
 
- Tablero de 3×3 con botones
- Dos jugadores en el mismo equipo, turnos alternados (X y O)
- Detección de ganador por filas, columnas y diagonales
- Detección de empate
- Mensaje de fin de juego y reinicio automático del tablero

## Tecnologías
 
- Python (probado con 3.14)
- tkinter (incluido con Python, no requiere instalar nada)

## Cómo se juega
 
1. El jugador **X** empieza.
2. Haz clic en una casilla vacía para marcarla.
3. Gana quien complete una fila, columna o diagonal.
4. Si el tablero se llena sin ganador, es empate.
5. Al terminar aparece un aviso y el tablero se reinicia.
